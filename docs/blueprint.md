# **App Name**: Fresher Folio

## Core Features:

- Personal Details Section: A section to showcase personal information, contact details, and a brief introduction.
- Skills Showcase: Visually display your skills using progress bars or charts.
- Projects Gallery: Dedicated section to show any school or side projects to show code samples.
- Certifications Display: Dedicated place to display Certificates.
- Resume Upload/Download: Allows potential employers to download the user's resume directly from the portfolio.

## Style Guidelines:

- Primary color: Soft blue (#A0CFEC) to evoke trust and professionalism.
- Background color: Light gray (#F0F0F0) for a clean, modern look.
- Accent color: Darker blue (#4682B4) to highlight important information and CTAs.
- Body font: 'Inter' sans-serif, for a clean, modern, objective feel.
- Headline font: 'Space Grotesk' sans-serif, for a computerized, techy feel.
- Use professional, minimalist icons for skills, contact information, and navigation.
- Maintain a clean, one-page layout with clear sections and a logical flow of information.
- Subtle scrolling animations or transitions to guide the user and enhance engagement.
